Rajasthan Media Gallery

A simple HTML-only media gallery showcasing some of the most popular tourist destinations in Rajasthan. This project demonstrates the proper use of images, captions, accessibility features, and embedded media using semantic HTML.

## Project Overview

This project was built to practice:

* Semantic HTML structure
* Image accessibility with alt text
* Figure and figcaption elements
* Decorative images
* Embedded media
* Video integration
* Proper document metadata

## Features

* Semantic page structure using:

  * `header`
  * `main`
  * `footer`

* Six images with:

  * Descriptive alt text
  * Width and height attributes

* Three images wrapped inside:

  * `figure`
  * `figcaption`

* One decorative image using:

  * `alt=""`

* Embedded Rajasthan tourism video

* Responsive viewport metadata

## Places Included

* Hawa Mahal, Jaipur
* Jaisalmer Fort
* Udaipur City Palace & Lake Pichola
* Mehrangarh Fort, Jodhpur
* Ranthambore National Park
* Pushkar Lake
